# RuSwitcher for Windows 0.10.0-beta.2 (Native x64 Parity Release)

Windows build and feature update based on [rashn/RuSwitcher](https://github.com/rashn/RuSwitcher) (Rashid Sayfutdinov | [ruswitcher.app](https://ruswitcher.app)).

> **Чистая нативная архитектура x64:** Сборки на .NET упразднены. Приложение распространяется исключительно как легковесный автономный 64-битный C++20 бинарник (~247 КБ) со статической линковкой (`/MT`, x64), без внешних зависимостей и без необходимости устанавливать .NET Runtime.

### Available Downloads:
- **`RuSwitcher-0.10.0-beta.2-native-x64.zip` (~139 KB)** 🚀 *Рекомендуемая автономная сборка*:
  Ультра-легковесный автономный C++20 Win32 бинарник без внешних зависимостей. Мгновенный запуск, минимальное потребление ОЗУ, 100% паритет с macOS 3.5.0b.
- **`RuSwitcher-0.10.0-beta.2-native-x64.exe` (~247 KB)**:
  Исполняемый файл, готовый к запуску без распаковки.

### Что нового в этом обновлении:
1. **Конвертация набранной фразы / строки в стиле Punto Switcher:**
   - Непрерывный буфер нажатий (`KeystrokeBuffer`) на основе эталонной реализации `RuSwitcher.Win` и macOS `KeyboardMonitor`.
   - При наборе одного, двух или нескольких слов (`ghbdtn vbh rfr ltkf`) программа сохраняет непрерывную цепочку ввода.
   - По нажатию горячей клавиши конвертируется **именно то, что набрано последним** (`BufferedLine`), без деструктивного выделения `Home` → `Shift+End` и без затирания текста в начале строки или консоли.
   - При нажатии `Backspace` буфер динамически восстанавливает предыдущее слово назад через пробелы (`rebuild_current_word`).
2. **Выбираемая область конвертации (Scope Selection):**
   - Возможность переключения режима:
     - **«Последнее слово / выделенный текст»** (`Word`)
     - **«Набранная фраза / строка (как в Punto Switcher)»** (`Phrase`)
     - **«Вся строка целиком от начала (Home → End)»** (`SystemLine`)
   - Переключение доступно прямо из контекстного меню трея (`Область конвертации ▶`) и из диалога `Настройки...`.
3. **Поддержка горячей клавиши Shift + Pause/Break:**
   - Мгновенная конвертация набранной строки/фразы по аналогии с Punto Switcher.
4. **Защита буфера обмена и исправление микрофризов:**
   - Полная сохранность буфера обмена пользователя (`ClipboardSnapshot`).
   - Устранены микрофризы при вызове команд из трея за счет точечной нормализации фокуса.
5. **Авто-конвертация и текстовые фиксы:**
   - Авто-конвертация слов со знаками препинания (`[jhjij` $\to$ `хорошо`, `rf;tncz` $\to$ `кажется`).
   - Исправление двух заглавных (`ПРивет` $\to$ `Привет`).
   - Исправление опечаток в цифрах (`1ю8` $\to$ `1.8`).
   - Запоминание раскладки для каждого приложения (`PerAppLayoutManager`).
