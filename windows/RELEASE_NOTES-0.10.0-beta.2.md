# RuSwitcher for Windows 0.10.0-beta.2 (macOS 3.5.0b Parity Release)

Windows build and feature update based on [rashn/RuSwitcher](https://github.com/rashn/RuSwitcher) (Rashid Sayfutdinov | [ruswitcher.app](https://ruswitcher.app)).

### Available Downloads:
- **`RuSwitcher-0.10.0-beta.2-native-x64.zip` (~131 KB / 224 KB exe)** 🚀 *Рекомендуемая автономная сборка*:
  Ультра-легковесный автономный C++20 Win32 бинарник без внешних зависимостей (не требует .NET или VC++ Redistributable, статическая линковка `/MT`). Мгновенный запуск, минимальное потребление ОЗУ, 100% паритет с macOS 3.5.0b.
- **`RuSwitcher-0.10.0-beta.2-win-x64-compact.exe` (~313 KB)**:
  .NET-клиент для систем с установленным .NET 8 / 9 / 10 Desktop Runtime.
- **`RuSwitcher-0.10.0-beta.2-win-x64-standalone.zip` (~65 MB)**:
  Полная самодостаточная .NET-версия со встроенным рантаймом.

### Что нового в этом обновлении:
1. **Выбираемая область конвертации (Scope Selection):**
   - Возможность переключения режима: **«Последнее слово / выделенный текст»** (по умолчанию) либо **«Вся строка целиком (Shift+Home)»**.
   - Переключение доступно прямо из контекстного меню трея (новое подменю `Область конвертации ▶` с радио-метками) и из диалогового окна `Настройки...` (выпадающий список).
2. **Исправление пунктов меню «Конвертировать текущую строку» и «Сменить регистр»:**
   - **Устранён микрофриз:** при вызове команд из трея системный фокус ввода надёжно возвращается в целевое окно пользователя через `AttachThreadInput` + `SetForegroundWindow` + `SetFocus`.
   - **Умная работа со словом:** пункт «Сменить регистр» теперь работает не только с предварительно выделенным мышью текстом, но и автоматически берет слово под курсором (`Ctrl+Shift+Left`), если текст не был выделен.
   - **Оптимизация таймаутов:** время ожидания ответа буфера обмена снижено до 100–180 мс, задержки интерфейса сведены к нулю.
   - **Двунаправленная конвертация (Bidirectional Fallback):** если раскладка клавиатуры рассинхронизирована с фактическим текстом (например, русский текст при активной EN раскладке), алгоритм распознаёт исходный алфавит и производит корректную конвертацию с переключением раскладки.

### В чём разница между режимами конвертации:
- **«Последнее слово / выделенный текст» (по умолчанию):**
  - Если фрагмент текста выделен мышью или клавиатурой $\to$ конвертируется **только выделенная часть**.
  - Если ничего не выделено (вы просто печатали текст) $\to$ конвертируется **только последнее введенное слово** (до пробела, знака препинания или начала строки). Все предыдущие слова остаются неизменными.
- **«Вся строка целиком (Shift+Home)»:**
  - Независимо от того, где стоит курсор на строке и сколько слов набрано, конвертируется **вся строка целиком** (от начала строки до курсора / конца строки). Удобно при слепом наборе, когда целое предложение набрано в неверной раскладке (`Ghbdtn! Rfr ltkf?` $\to$ `Привет! Как дела?`).
