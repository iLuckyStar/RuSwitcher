🧪 Бета RuSwitcher 3.5.0b

Что нового:
• Автоконверсия может срабатывать и на Enter и Tab, не только на пробеле. Пригодится в адресной строке браузера и в мессенджерах, где слово часто последнее перед отправкой. Настройки → Автоконверсия, по умолчанию выключено: в мессенджере Enter сразу отправляет сообщение вместе с исправленным словом.
• Автозамена сокращений: задаёте "сув" → "С уважением, Иван", и сокращение разворачивается при наборе. Раскладка и регистр не важны.
• Исправление двух заглавных подряд (КОгда → Когда) и явных опечаток: одна соседняя клавиша (тедефон → телефон) и точка или запятая, набранные в русской раскладке между цифрами (1ю8 → 1.8). По умолчанию выключено.
• Имена и названия, которые словарь знает только с заглавной, теперь узнаются: zyltrc → яндекс, fdbnj → авито.
• Исправлен рост памяти при долгой работе.

Как получить: Настройки → Расширенные → "Получать бета-версии (для тестирования)", потом "Проверить обновления". Или DMG со страницы релиза:
https://github.com/rashn/RuSwitcher/releases/tag/v3.5.0b

Если что-то ведёт себя не так, пишите здесь в чате или в issues:
https://github.com/rashn/RuSwitcher/issues

🧪 RuSwitcher beta 3.5.0b

What's new:
• Auto-conversion can also trigger on Enter and Tab, not only on Space. Handy in the browser address bar and in messengers. Settings → Auto-conversion, off by default: in a messenger Enter sends the message right away, together with the fixed word.
• Abbreviations: set "brgds" → "Best regards, Alex" and it expands as you type. Layout and case don't matter.
• Optional fixes for two capitals in a row (THis → This) and obvious typos (hwllo → hello). Off by default.
• Names the dictionary knows only capitalized are now recognized: zyltrc → яндекс.
• Fixed memory growth during long sessions.

Get it: Settings → Advanced → "Get beta versions (for testing)", then "Check for Updates…". Or the DMG from the release page above.
